I'm a full-stack developer — I take products from an empty repo to a shipped MVP across the whole stack: React/Next.js on top, Go or Python underneath, a real database and CI behind it. Recent work spans a metered SaaS portal, a React + Go security dashboard, and an agency site with its own bot backend. I like small diffs, boring dependencies, and code someone else can still read at 3 a.m.

**Open to freelance / contract work** — full-stack product work, from UI to infra.
